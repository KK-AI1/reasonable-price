# DESIGN.md — UI・デザイン方針

Claude Code は UI を作る・変えるときに必ずこのファイルに従ってください。
数値（色・サイズ・余白）は `src/styles/tokens.css`（CSS変数）に定義し、Tailwind 設定からそれを参照すること。コンポーネントに色コードやサイズを直接書かないこと。

---

## 1. デザインの方向性（一言で）

**「Grab のように見慣れた操作感」＋「Wise のような数字の信頼感」＋「明るく穏やかなトーン」**

- 東南アジアの旅行者が使い慣れた配車アプリ（Grab）に近い配置にし、説明なしで使えるようにする
- 金額と判定は、大きく、正確に、すっきり見せる
- 「ぼったくり撃退」ではなく「納得の価格で買う」。売り手を敵視する表現・色使いをしない

## 2. 設計の根拠（判断に迷ったらここに戻る）

| 原則 | 根拠 | このアプリでのルール |
| --- | --- | --- |
| 見慣れた形にする | ヤコブの法則：ユーザーは他のアプリと同じ動きを期待する | ホームは「検索バー → アイコングリッド → 情報カード → 下部タブ」の配置 |
| アイコンに文字を添える | NN/g の研究：アイコン単体は意味が伝わりにくい | すべてのアイコンに日本語ラベルを付ける。アイコンだけのボタンは作らない |
| 親指で届く位置 | Hoober (2013)：片手・親指操作が多く、画面下部ほど押しやすい | 主要ボタン・入力は画面の中央〜下部。重要な操作を画面上部の端に置かない |
| 選択肢を絞る | ヒックの法則：選択肢が多いほど選ぶのに時間がかかる | ホームのアイコンは最大6個。1画面の主ボタンは1つ |
| 最初の金額を目立たせる | アンカリング研究（Galinsky & Mussweiler 2001 など）：最初に出た金額が交渉の基準になる | 交渉コーチでは「最初に言う金額／次に言う金額」を画面で最大の文字にする |
| 信頼を守る | 判定の近くに広告があると中立性が疑われる | 価格の判定・交渉コーチ画面に広告やプロモーションを置かない |

## 3. カラー

Grab の緑（#00B14F 付近）とは**明確に区別できる青緑（ティール）**をブランド色にする。公式アプリや提携アプリと誤解されないため。

| トークン | 値 | 用途 |
| --- | --- | --- |
| `brand` | `#0F8B8D` | ヘッダー、主ボタン、選択中のタブ |
| `brand-soft` | `#E3F4F3` | アイコンの丸背景、選択中の背景 |
| `bg` | `#F7F8F6` | 画面の背景 |
| `surface` | `#FFFFFF` | カード |
| `text` | `#1F2A2E` | 本文 |
| `text-sub` | `#5E6B70` | 補足、内訳 |
| `border` | `#E2E6E4` | 区切り線、カードの枠 |
| `fair` | `#2E9E5B` | 判定：妥当 |
| `caution` | `#E0A21B` | 判定：やや高い |
| `high` | `#D2553F` | 判定：高すぎる |
| `accent` | `#F2B84B` | 「今ここ」などの小さな強調、バッジ |

ルール：
- 判定の3色（fair / caution / high）は**判定の表示にだけ**使う。装飾に使わない
- 赤（high）は面積を小さく。背景を赤で塗りつぶさない
- 色だけで意味を伝えない。判定には必ず文字（「妥当」「やや高い」「高すぎる」）とアイコンを添える
- 文字と背景のコントラストは WCAG AA（4.5:1）以上
- ダークモードはMVPでは対応しない（2版目）

## 4. タイポグラフィ

- フォント：`"Noto Sans JP", system-ui, sans-serif`（数字は `font-variant-numeric: tabular-nums`）
- サイズ（px）

| トークン | サイズ / 太さ | 用途 |
| --- | --- | --- |
| `display` | 40 / 700 | 交渉コーチの「次に言う金額」、運賃チェックの適正額 |
| `title` | 20 / 700 | 画面タイトル |
| `heading` | 16 / 700 | カードの見出し |
| `body` | 15 / 400 | 本文 |
| `label` | 12 / 500 | アイコンのラベル、バッジ |
| `caption` | 12 / 400 | 出典、免責、円換算 |

- 金額は「現地通貨（大）＋円換算（小）」の2段で表示する。例：`350 バーツ`（大）／`約1,600円`（小）
- 文字の最小サイズは 12px

## 5. レイアウトと余白

- 基準の画面幅：375px（最小 320px で崩れないこと）
- 余白の単位：4px の倍数（4, 8, 12, 16, 24, 32）
- 画面の左右の余白：16px
- 角丸：カード 16px、ボタン 12px、アイコンの背景は円
- タップできる要素は最小 44×44px
- 影は使わないか、ごく弱く（`0 1px 2px rgba(0,0,0,0.06)`）

## 6. 画面ごとの設計

### 6.1 ホーム（Grab 風）

上から順に：

1. **ヘッダー**（`brand` 背景）：検索バー「何を買いますか？」（品目検索）
2. **現在地の行**：「📍 バンコク・チャトゥチャック市場」＋売り場の種類（タップで変更）。Grab の「Ride to」の行に相当
3. **アイコングリッド**（4列、最大6個）
   - 大きく（2列分の幅）：**タクシー運賃**、**市場の買い物**
   - 小さく：トゥクトゥク／交渉コーチ／フレーズ帳／交渉しない場所
   - 各アイコンは `brand-soft` の丸背景＋下に日本語ラベル（`label`）
4. **情報カード**（Grab のバナーの位置）：「この街の注意点」「今日の交渉のコツ」。**広告は置かない**
5. **下部タブ**：ホーム／履歴／フレーズ／設定（アイコン＋ラベル）

### 6.2 運賃チェック

- 入力（距離、停車時間、空港）は画面の中央〜下部
- 結果カード：適正額（`display`）→ 判定バッジ（色＋文字＋アイコン）→ 内訳（折りたたみ）→ 出典と確認日（`caption`）
- 「メーターを使ってください」のタイ語フレーズをカードで表示

### 6.3 市場の買い物（2画面）

**① 商品を探す（一覧）**

- 上から：現在地の行「📍 バンコク ＞ 市場を選ぶ」（タップで売り場を選ぶシート）→ 検索欄「商品名で探す」→ 分類のチップ（すべて／衣類／バッグ・財布／雑貨／工芸品／美容・食品／時計・メガネ。横にスクロール）
- 商品カード：画像（今はアイコン。写真は権利を確認したものに差し替える）＋商品名＋仕様（例：薄手・一般的な生地）＋価格帯「100〜225 THB / 1枚」＋「情報 ◯件・未確認」
- 価格帯が出せない品目は「価格情報が不足しています」、定価の品目は「定価で買う品物です」と表示
- 一番下に「最近見た商品」（端末にだけ保存）

**② 商品の相場（詳細）**

- 商品カード（画像・名前・仕様）＋「商品を変更」
- 売り場の行「バンコク / 一般の市場」＋「条件を変更」
- 数量（－ 1 ＋）
- 価格帯カード：「納得できる価格帯」→ 価格帯（`display`）＋「1枚あたり」→ 円換算 → 目安 → 情報の件数と換算レート → 折りたたみ「価格の根拠を見る」「素材・サイズの違いを確認」
- 「提示された金額を入力（任意）」：入れると判定バッジ（色＋文字＋アイコン）
- 屋台・モールなどを選んだときは「ここは交渉しない場所です」カード（`brand-soft` 背景）
- 主ボタン「現地語で値段を相談する」を画面下部に固定。下に「再生する前に日本語で確認できます」

### 6.4 交渉コーチ（最重要画面）

- 画面の主役は「最初に言う金額／次に言う金額」（`display`、中央）
- その下に「なぜこの金額か」を1〜2行（`body` / `text-sub`）
- 相手の返答額の入力欄と「更新」ボタンは**画面下部に固定**（親指で届く位置）
- 「相手に見せる」ボタン：金額とタイ語の一言を全画面・白背景・特大文字で表示
- 交渉の履歴は折りたたみ
- 「買いましょう」「立ち去りましょう」の判断が出たら、判定色のバッジで表示

## 7. 言葉づかい（トーン）

| 使う | 使わない |
| --- | --- |
| 納得の価格、目安、交渉の余地あり | ぼったくり、撃退、カモ、詐欺（判定文では使わない） |
| 「やや高めです。少し交渉してみましょう」 | 「騙されています！」 |
| 「ここは交渉しない場所です」 | 「値切れません」 |
| 「笑顔でお礼を言って立ち去りましょう」 | 「無視して帰りましょう」 |

- 敬体（です・ます）。短く、1文25文字程度まで
- 感嘆符は多用しない

## 8. アイコン

- ライブラリ：`lucide-react`（線の太さ 2px、サイズ 24px）
- 必ず日本語ラベルを添える
- 他社のロゴ・キャラクター・ブランドアイコンを使わない（Grab のアイコンも模倣しない）

## 9. アクセシビリティ

- コントラスト WCAG AA 以上
- タップ領域 44×44px 以上
- 色だけで判定を伝えない（文字＋アイコンを併用）
- 画像・アイコンには `aria-label`
